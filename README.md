# Illuminati Organization Shop

A simple static ecommerce starter website.

## Files
- `index.html` — homepage and products
- `cart.html` — cart
- `script.js` — cart functionality
- `styles.css` — responsive styling
- `privacy.html` — privacy-policy placeholder
- `terms.html` — terms placeholder

## Before launch
Replace placeholder business information, product details, prices, policies and contact information. Connect a legitimate payment processor and shipping/order workflow before accepting customer payments.
